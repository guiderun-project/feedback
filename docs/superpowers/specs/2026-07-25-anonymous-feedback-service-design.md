# 익명 의견 제출 서비스 설계

- 상태: 설계 승인됨 (구현 계획 단계로 이동 예정)
- 작성일: 2026-07-25
- 대상 도메인: `feedback.guiderun.org`

## 배경 및 목적

가이드런 프로젝트가 운영하는 훈련 프로그램의 참가자가 로그인이나 개인정보 입력 없이 **익명으로 의견을 남길 수 있는** 단일 목적 웹 서비스를 만든다. 운영 비용은 0원에 가까워야 하고, 레이아웃과 기능은 최대한 단순하게 유지한다.

## 비범위 (하지 않을 것)

- 관리자 페이지를 만들지 않는다. 운영자는 연결된 Google 스프레드시트를 직접 열어서 의견을 확인한다.
- 참가자 로그인/인증, 회차·기수 구분 입력 필드를 두지 않는다.
- 이름, 이메일 등 식별 가능한 정보를 입력받거나 수집하지 않는다.
- 제출된 의견을 프론트엔드에서 수정/삭제하는 기능을 만들지 않는다 (필요하면 운영자가 시트에서 직접 처리).

## 전체 아키텍처

```
[참가자 브라우저]
   └─ feedback.guiderun.org (정적 페이지, Netlify 호스팅)
        └─ fetch(POST) → Google Apps Script Web App URL
             └─ Apps Script가 연결된 Google Sheet에 [날짜, 내용] 행 추가

[운영자] → Google Sheet를 직접 열람 (관리자 페이지 없음)
```

- 서버·DB 비용 0원: Netlify 무료 티어 + Google Apps Script(무료) + Google Sheets(무료)
- 제3자 서비스 의존 없음. Google 계정과 Netlify 계정만으로 완결.

## 데이터 모델

Google Sheets 시트 하나에 컬럼 2개만 사용한다.

| 열 | 내용 |
|---|---|
| A | 제출 일시 (타임스탬프) |
| B | 의견 내용 (자유 텍스트) |

스프레드시트 자체는 비공개 공유 설정을 유지한다. Apps Script 웹 앱 엔드포인트만 공개하고, 시트 링크는 운영자만 소유한다.

## 프론트엔드

### 구성
- 단일 페이지, 순수 정적 HTML/CSS/최소 JS (프레임워크 불필요)
- 화면 요소: 그룹명 + 페이지 제목 + 안내문구 + 자유 텍스트 입력창(textarea) + 제출 버튼
- 모바일 우선 반응형 레이아웃 (QR코드/링크로 폰에서 접속하는 상황을 기본 가정)

### 화면 목업 (텍스트)

```
┌─────────────────────────────────┐
│ [favicon]   가이드런 프로젝트       │  ← 상단에 작게 그룹명 표시
│                                  │
│      훈련 프로그램 의견함           │  ← 페이지 제목
│                                  │
│  자유롭게 의견을 남겨주세요.         │  ← 안내문구
│  익명으로 제출되며, 어떤 개인정보도   │
│  수집하지 않습니다.                │
│                                  │
│  ┌────────────────────────┐    │
│  │                          │    │  ← 큰 textarea
│  │                          │    │
│  └────────────────────────┘    │
│                                  │
│          [ 제출하기 ]              │  ← 버튼 (포인트 컬러 1개만 사용)
└─────────────────────────────────┘
```

제출 후 textarea/버튼 영역은 "의견이 제출되었습니다. 감사합니다 🙏" 완료 문구로 전환된다.

### 톤앤매너
- 배경: 흰색 또는 아주 옅은 회색, 여백 넉넉하게
- 포인트 컬러: 버튼 등에만 색 하나 사용. 기본값은 파란색 계열(`#2563EB`)로 하되, 구현 중 조정 가능
- 폰트: 웹폰트 로드 없이 시스템 기본 폰트 사용 (로딩 가볍게)
- 브라우저 탭 제목: "가이드런 프로젝트 - 의견함"
- Favicon: `guiderun.org`에서 실제 사용 중인 파일을 그대로 가져와 적용

### 검색 노출 차단
- `<meta name="robots" content="noindex, nofollow">` 태그 추가
- `robots.txt`에 전체 차단 규칙(`Disallow: /`) 추가

이 페이지는 공개적으로 접근 가능한 URL이지만 검색엔진에는 노출되지 않아야 한다 (링크나 QR코드를 아는 사람만 접근).

### 스팸 방지
- 화면에는 보이지 않는 honeypot 입력 필드를 하나 추가한다. 해당 필드가 채워진 상태로 제출되면 정상적인 사용자 응답인 것처럼 보이되 백엔드에서 조용히 무시한다 (자동화된 봇의 단순 스팸을 걸러내는 목적).

## 백엔드 (Google Apps Script)

- 스프레드시트에 바인딩된 Apps Script 프로젝트를 만든다.
- `doPost(e)` 함수가 요청 바디에서 의견 텍스트를 읽어 시트에 `[new Date(), 내용]` 행을 추가한다. honeypot 필드가 채워져 있으면 아무 것도 기록하지 않고 정상 응답만 반환한다.
- "웹 앱으로 배포" (실행: 나, 액세스 권한: 모든 사용자)로 공개 엔드포인트를 생성한다. 이 URL이 실질적인 API 역할을 한다.
- 프론트엔드는 요청 시 `Content-Type: text/plain`으로 본문을 전송해 브라우저의 CORS preflight(OPTIONS) 요청을 발생시키지 않는다. Apps Script는 preflight 처리를 지원하지 않으므로, 이 방식으로 보내야 정상적인 JSON 응답을 받아 성공/실패를 구분할 수 있다.

## 배포 & 도메인

- 정적 파일을 Netlify에 배포한다 (기존에 사용 중인 계정 활용).
- Netlify 사이트 설정에서 커스텀 도메인으로 `feedback.guiderun.org`를 추가한다.
- `guiderun.org`의 DNS(도메인 관리 콘솔)에 Netlify가 안내하는 CNAME 레코드를 추가한다.

## 운영자(계정 소유자)가 직접 해야 하는 수동 설정

아래 항목은 Google/도메인 계정 인증이 필요해 대리 수행이 불가능하다. 코드/설정 파일은 구현 단계에서 모두 준비하고, 아래는 절차 안내만 제공한다.

1. Apps Script 편집기에 코드를 붙여넣고 "배포 → 웹 앱으로 배포" 클릭 후 Google 권한 승인
2. Netlify에서 리포지토리 연결 및 배포
3. `guiderun.org` DNS에 `feedback` 서브도메인용 CNAME 레코드 추가
4. Google 스프레드시트 공유 설정을 비공개로 유지 (Apps Script 엔드포인트만 공개)

## 에러 처리

- 네트워크 오류 또는 Apps Script 응답 실패 시: "제출에 실패했습니다. 다시 시도해주세요" 메시지를 보여주고 입력한 텍스트는 그대로 유지한다 (재입력 방지).
- 빈 내용은 클라이언트에서 제출 자체를 막는다 (제출 버튼 비활성화 또는 제출 시 검증).
- Google 측 장애(Apps Script/Sheets 다운)는 통제 범위 밖이므로 별도 재시도 로직 없이 사용자에게 재시도를 안내하는 수준으로 처리한다.

## 테스트 방법

별도 자동화 테스트 없이 수동 체크리스트로 충분하다 (1페이지, 저트래픽 서비스).

- 정상 제출 → 스프레드시트에 정확히 기록되는지 확인
- 빈 내용 제출이 막히는지 확인
- honeypot 필드가 채워진 제출이 시트에 기록되지 않는지 확인
- 모바일 화면에서 레이아웃 확인
- `site:feedback.guiderun.org` 등으로 검색엔진 색인 여부 주기적 확인
